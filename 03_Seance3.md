# Séance 3 — Évaluation, approfondissement et projet cartographique final

# Matin (9h–12h) — DST méthodologique et approfondissement

## 🎯 Objectifs

Vérifier les acquis, identifier les incompréhensions et consolider les méthodes avant le travail individuel final.

## 9h–10h30 — DST méthodologique individuel

Le DST porte sur le **raisonnement cartographique** :

- reconnaître la nature d'une donnée ;
- distinguer stock et taux ;
- choisir une représentation ;
- expliquer une jointure ;
- identifier une clé ;
- diagnostiquer une jointure incomplète ;
- interpréter une table attributaire ;
- analyser une carte et ses choix graphiques ;
- expliquer la démarche permettant de passer d'un tableau à une carte.

> **Le DST constitue la première note finale du module.**

## 10h30–12h — Correction et approfondissement

La correction sert à repérer ce qui reste mal compris. Selon les difficultés observées, l'enseignant reprend les notions ou manipulations nécessaires : import CSV, jointures, identifiants, stock/taux, symbologie, discrétisation, SCR, table attributaire ou mise en page.

Les étudiants peuvent également poser des questions directement liées à leur projet final.

# Après-midi (13h–16h) — Atelier final : réaliser sa propre carte dans QGIS

## 🎯 Objectif

Mobiliser l'ensemble du module pour produire une carte personnelle à partir des données recherchées et préparées depuis la séance 1.

## Travail demandé

Chaque étudiant·e doit :

1. formuler clairement ce qu'il/elle souhaite montrer ;
2. présenter la source, la date et l'unité des données ;
3. préparer et importer les données ;
4. choisir un fond géographique adapté ;
5. réaliser une jointure si nécessaire ;
6. vérifier et corriger le résultat ;
7. choisir une représentation adaptée ;
8. définir la symbologie et la discrétisation ;
9. construire une mise en page complète ;
10. exporter la carte finale.

## 🤝 Un travail individuel accompagné

L'étudiant·e réalise lui-même / elle-même sa carte. L'enseignant circule et aide à diagnostiquer les difficultés : CSV mal importé, identifiants incompatibles, données manquantes, couches qui ne se superposent pas, mauvais choix de représentation, classification peu lisible, problème de mise en page, etc.

L'objectif de l'aide est de **comprendre et résoudre le problème**, pas de réaliser la carte à la place de l'étudiant·e.

## 📝 Deuxième note finale

La carte produite constitue la deuxième note finale. L'évaluation porte notamment sur :

- pertinence de la question et des données ;
- qualité et traçabilité des sources ;
- préparation des données ;
- maîtrise de la jointure lorsqu'elle est nécessaire ;
- adéquation donnée / représentation ;
- sémiologie graphique ;
- lisibilité ;
- mise en page ;
- capacité à expliquer et justifier les choix.

## ✅ Bilan du module

**Chercher → comprendre → créer → joindre → représenter → vérifier → corriger → produire.**
