# Initiation à la cartographie avec QGIS

**Master 2 EEI-MCRI — CY Cergy Paris Université**  
**18 heures — 3 séances de 6 heures**

Bienvenue sur le site pédagogique du cours **Initiation à la cartographie pour non-spécialistes**.

Ce site regroupe le cours, les méthodes, les exercices pratiques sous QGIS et les ressources nécessaires pour passer progressivement d'une question de recherche à une carte thématique aboutie.

## 🚀 Par où commencer ?

Commencez par la page **Introduction**. Elle présente les objectifs, l'organisation des 18 heures, les deux évaluations et surtout le **projet cartographique individuel** à préparer dès la première séance.

👉 [Commencer le cours — Introduction](00_Introduction.html)

## 🧭 Fil conducteur du cours

**Question → recherche des données → compréhension des données → QGIS → création de données → jointure → représentation → mise en page → carte finale**

L'objectif est de comprendre la démarche cartographique, pas seulement d'apprendre à cliquer dans un logiciel.
