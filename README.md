# Initiation à la cartographie avec QGIS - M2 EEI-MCRI

Site pédagogique du module **Initiation à la cartographie avec QGIS**, destiné aux étudiant·es du **Master 2 EEI-MCRI - Études Européennes et Internationales / Mondes Contemporains et Relations Internationales** de **CY Cergy Paris Université**.

Le module représente **18 heures d'enseignement**, organisées en **3 séances de 6 heures**.

L'objectif est d'acquérir les bases nécessaires pour comprendre une démarche cartographique et réaliser une carte simple avec QGIS, depuis la formulation d'une question et la recherche des données jusqu'à la représentation et à la mise en page finale.

## Structure du cours

- **Accueil**
- **Introduction - Présentation du module**
- **Séance 1 - De la question de recherche aux données cartographiques et découverte de QGIS**
  - recherche et compréhension des données ;
  - découverte de QGIS ;
  - création et représentation de données ;
  - réalisation d'une première carte.
- **Séance 2 - Préparer les données et réaliser une carte thématique**
  - préparation des données ;
  - jointure attributaire et introduction à la jointure spatiale ;
  - cartographie thématique ;
  - représentation et mise en page.
- **Séance 3 - Consolider les acquis et réaliser son projet cartographique**
  - retour sur les notions et manipulations étudiées ;
  - consolidation des acquis ;
  - réalisation du projet cartographique individuel.
- **Ressources - Données, QGIS et fonds cartographiques**

## Fil conducteur

Le cours suit progressivement la démarche suivante :

**Question → Données → Préparation → QGIS → Représentation → Mise en page → Carte finale**

Le projet cartographique individuel constitue le **fil rouge du module**. Les étudiant·es commencent à réfléchir à leur sujet et à rechercher leurs données dès la première séance.

## Publication GitHub Pages

Le site est conçu pour être publié avec **GitHub Pages / Jekyll**.

Pour le mettre en ligne :

1. créer un dépôt GitHub ;
2. copier les fichiers du site à la racine du dépôt ;
3. publier les modifications sur la branche `main` ;
4. activer **GitHub Pages** dans les paramètres du dépôt.

Le site utilise le thème configuré dans les fichiers Jekyll du projet.
