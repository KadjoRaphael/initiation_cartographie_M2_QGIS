# Initiation à la cartographie avec QGIS — M2 EEI-MCRI

Site pédagogique GitHub Pages/Jekyll pour un module de 18 h à CY Cergy Paris Université.

## Structure

- Accueil
- Introduction
- Séance 1 matin : recherche de données
- Séance 1 après-midi : QGIS et création de données
- Séance 2 matin : jointures
- Séance 2 après-midi : cartographie thématique
- Séance 3 : DST, approfondissement et projet final
- Ressources

## Publication GitHub Pages

Créer un dépôt, copier ces fichiers à la racine, puis activer GitHub Pages depuis la branche `main`. Le site utilise le même thème distant que le site pédagogique de référence.
